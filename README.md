# Design Template

A responsive education landing page built with React Router v7 and Bootstrap 5.

## Features

- **Modular Architecture**: Built with React components and CSS Modules for isolated styling.
- **Dynamic UI**: 
  - Transparent-to-white Navbar on scroll.
  - Native React-state driven mobile navigation (no Bootstrap JS dependency).
  - Modern typography using the Montserrat font family.

## Local Setup

To run the project locally, use the setup script:

```bash
npm run setup
```

This will install dependencies and start the development server at [http://localhost:5173](http://localhost:5173).

## Tech Stack

- **Framework**: React Router v7 (Vite) (SSR false and Prerender true)
- **Styling**: Bootstrap 5 (Grid & Utilities), CSS Modules
- **Font**: Montserrat (via Google Fonts)
